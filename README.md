# TUM International Exchange Course Project

这是一个面向 TUM 国际交流课程的团队 Business Idea 项目。课程重点不是展示最复杂的机器人技术，而是从真实生活问题出发，完成一条清晰、可解释、具有商业价值的推理链：

**Problem → Root Cause → HMW → Co-Creation → Solution → User Value → Business → 5-minute Pitch**

## 项目当前定位

- **Problem:** People often waste time looking for small everyday items at home.
- **Root Cause:** Object locations constantly change, but they are not continuously tracked or managed.
- **How Might We:** How might we help people easily find and organize everyday objects at home?
- **Current solution direction:** Smart Home Organization Robot
- **Core interaction:** **SEE → REMEMBER → FIND → ORGANIZE**
- **User value:** Save time. Reduce stress. Make everyday life easier.

当前仍处于项目初始化和方案收敛阶段。核心方向已确定，但 MVP 范围、目标用户优先级、机器人形态、交互方式、商业细节和最终展示形式仍未最终决定。

## 证据规则

目前文档中的项目内容主要来自 `AGENTS.md`，不是市场调查结果。没有可靠证据的内容必须标记为 `Assumption`、`Hypothesis`、`Proposed direction` 或 `Future validation`。不得自行补充市场规模、价格、用户反馈、技术性能或竞争对手结论。

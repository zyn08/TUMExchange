# Project Brief / 项目简报

## 一句话定位

我们希望帮助人们更容易找到并整理家中的小型日常物品；当前选择探索一种 Smart Home Organization Robot。

**We want to help people easily find and organize everyday objects at home.**

## 当前已确定内容

| 项目 | 工作版本 |
|---|---|
| Daily problem | People often waste time looking for small everyday items at home. |
| Root Cause | Object locations constantly change, but they are not continuously tracked or managed. |
| HMW | How might we help people easily find and organize everyday objects at home? |
| Solution direction | Smart Home Organization Robot |
| Core interaction | SEE → REMEMBER → FIND → ORGANIZE |
| User value | Save time. Reduce stress. Make everyday life easier. |
| Final deliverable | Approximately 5-minute team Business Idea Presentation |

## 当前目标用户候选

学生、宿舍居住者、独居年轻人、合租者、忙碌家庭是候选群体。它们是 `Potential users`，不是已经验证的 Customer Segments。老年人、辅助生活场景、酒店等属于潜在未来市场。

## 项目边界

第一版不应被描述为“什么都能整理”的万能家务机器人。更可信的工作假设是：

> A lightweight indoor robot tracks selected everyday objects, helps users find them, and organizes a limited set of supported items.

这句话仍是 `Proposed direction`，需要通过用户访谈、场景观察和原型验证。

# Final Presentation / 最终汇报

## 目标

约 5 分钟的国际课堂 Business Idea Presentation。最终材料应适合口述，不应成为学术论文汇报。

## 推荐时间结构

| 时间 | 内容 | 目标 |
|---|---|---|
| 0:00–0:30 | Attention Grabber + Problem | 先让观众想到“找不到钥匙”的真实瞬间 |
| 0:30–1:20 | Problem analysis + Root Cause | 简要说明用户、5 Whys 和深层问题 |
| 1:20–1:40 | HMW | 展示开放式问题 |
| 1:40–2:20 | Co-Creation / alternatives | 说明考虑过 storage、tags、camera、app、robot |
| 2:20–3:30 | Solution | 用 SEE → REMEMBER → FIND → ORGANIZE 讲清方案 |
| 3:30–4:30 | User Value + Business | 目标用户、价值和基本收入假设 |
| 4:30–5:00 | Closing | 回到开场场景，留下简单结论 |

## 工作英文素材

- Attention grabber: **Have you ever been late because you couldn't find your keys?**
- Problem: **People often waste time looking for small everyday items at home.**
- HMW: **How might we help people easily find and organize everyday objects at home?**
- Value: **Save time. Reduce stress. Make everyday life easier.**
- Closing direction: **Next time you can't find your keys, don't search the whole room. Just ask your robot.**

这些是工作句子，不代表最终脚本。最终英文应继续保持短句、常用词、容易发音，并由团队成员实际试读和计时。

## 展示设计约束

后续若制作 HTML：以 16:9 教室投影为目标，visual-first，少文字，突出 Problem → Solution 和 SEE → REMEMBER → FIND → ORGANIZE；默认支持全屏、键盘翻页和离线运行。必须有 10–20 秒 Attention Grabber。

# Business Model / 商业模式工作版

本文件只记录当前假设，不把候选项写成已验证事实。

## Value Proposition

> **Save time and reduce everyday frustration by helping users find and organize frequently used objects.**

中文：帮助用户找到并整理常用物品，节省时间，减少日常烦恼。

## Business Model Canvas（working version）

| 模块 | 当前候选 / 假设 |
|---|---|
| Customer Segments | Students、young people living alone、shared apartments、busy families；需进一步确定首要群体 |
| Channels | Online sales、electronics retailers、smart-home platforms、university communities |
| Customer Relationships | Mobile app、voice interaction、software updates、support、personalized settings |
| Revenue Streams | 首选讨论 hardware sales；premium service / subscription 仅作为未来可选假设 |
| Key Resources | Robot hardware、software、perception、navigation、manipulation、manufacturing |
| Key Activities | Product development、testing、maintenance、support、manufacturing |
| Key Partners | Component suppliers、robot manufacturers、smart-home companies、retailers |
| Cost Structure | Hardware、manufacturing、software、testing、maintenance、distribution、marketing |

## 当前商业风险

- 目标用户过宽，可能导致价值主张不够具体。
- 硬件成本、维护成本和用户支付意愿没有证据。
- “找东西”和“整理东西”可能是两个不同优先级，需要验证。
- 机器人能否安全、可靠地处理不同物品仍是技术和产品风险。

汇报时不机械朗读九个画布模块；只展示能支持“谁需要、得到什么、为什么可能付费”的少数关键内容。
